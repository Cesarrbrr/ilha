# +1.000 Dinâmicas para o Ano Inteiro

Landing page independente para a oferta de atividades e dinâmicas pedagógicas.

## Desenvolvimento
- React + TypeScript + Vite
- Identidade visual verde-água suave com fundo creme
- Página responsiva com hero, amostras ilustrativas, benefícios, categorias, bônus, oferta, garantia e FAQ.

## Antes de publicar
1. Substituir as prévias ilustrativas pelas imagens reais dos materiais fornecidos.
2. Confirmar o nome comercial final e a descrição precisa do conteúdo.
3. Definir os preços e os planos.
4. Inserir o link real do checkout.
5. Confirmar a política de garantia e as condições de acesso.
6. Substituir os textos de demonstração por depoimentos reais autorizados, se houver.

Os valores, o checkout e as condições comerciais foram deixados sem afirmações inventadas.
